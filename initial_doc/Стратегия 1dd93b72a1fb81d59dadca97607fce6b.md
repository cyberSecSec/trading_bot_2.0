# Стратегия

Правильный путь:

**Системная реакция в зависимости от рыночной среды.**

То есть:

- На рынке **не все манипуляции активны одновременно**
- Алгоритмы HFT работают в **режимах**, не в хаосе
- Значит, тебе нужен **контекстный режим-контроллер**, который:
    - Определяет, **какая группа манипуляций активна**
    - Переключает **подстратегии/фильтры/риск-профиль** под текущий тип шума

### **Как это устроить архитектурно**

- **1. Раздели манипуляции по типу рыночного поведения**
    
    Пример:
    
    | **Тип среды** | **Активные манипуляции** |
    | --- | --- |
    | Волатильная/импульсная | Spoofing, Volume Injection, Trap Fade |
    | Боковик | Layering, Absorption, Iceberg Play |
    | Разреженный стакан | Depth Ping, Phantom Wall, Liquidity Pull |
    | Пост-новость | Aggr. Flush, Trap Stop Chaining, Sucker Spike |
    
    Это **режимы рынка** → к ним привязываются **активные фильтры и реакция бота**
    
- **2. Создай "матрицу манипуляций"**
    
    В строках — твои 22 манипуляции.
    
    В столбцах:
    
    - Метрики
    - Сценарий активации
    - Поведение после (импульс, флэт, разворот)
    - Поведение бота (вход, выход, ожидание)
    - Подходит ли под short / long
    
    → Ты получишь **боевую матрицу действий** — она заменяет “интуицию” в моменте.
    
- **3. Реализуй “идентификатор среды”**
    
    По типу:
    
    - Объёмные всплески без продолжения
    - OI + ликвидации без направления
    - Дисбаланс по глубине/дельте/скорости смены стакана
    
    → Это **режим управления фильтрами**.
    
    Ты не используешь 22 стратегии постоянно. Ты их **включаешь/отключаешь в зависимости от сигнала среды**.
    

### **II. Как реализовать в логике стратегии**

1. **Слой “Контекст”: Определение рыночного режима**

```python
if delta > X and range < Y and OI ↑:
context = "trap_mode"
elif volume_spikes + strong follow-through:
context = "momentum"
elif no-trade zones + repeated walls:
context = "layering"
```

1. **Слой “Активация фильтров”: Включение нужных детекторов**

```python
if context == "trap_mode":
enable([MomentumTrap, StairStepHunt, ExecutionAbsorption])
```

1. **Слой “Реакция”: Логика бота по активным фильтрам**

```python
if MomentumTrap.triggered and not follow_up:
block_entry(direction="long")
monitor for reversal_signal
```

### **III. Что советую внедрить прямо сейчас**

1. **Кластер всех 22 манипуляций — с привязкой к рыночному режиму**
2. **Контекст-модель**, которая включает нужные блоки логики
3. **Сценарный симулятор** — чтобы проигрывать 10-минутные куски рынка и смотреть, какие из 22 сработали
4. **Не пытайся входить в рынок “по каждой манипуляции”** — реагируй **по блокам**, а не по фрагментам

**Краткий принцип:**

**Ты не ловишь манипуляции — ты ловишь алгоритм, который их использует в определённой фазе рынка.**

- Построить **структуру дерева состояний/режимов**
- Разметить все 22 манипуляции по типу среды
- Создать **модуль переключения стратегий** по текущему контексту
