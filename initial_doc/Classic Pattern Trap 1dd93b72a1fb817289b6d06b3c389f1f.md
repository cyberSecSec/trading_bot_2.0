## Манипуляция №13: Забор ликвидности на “классике” (Classic Pattern Trap)

### I. Что это и как работает

**Суть манипуляции:**

Алгоритм **не формирует паттерн сам**, а **распознаёт готовую структуру**, построенную толпой (треугольник, голова-плечи, флаг и т.д.), и атакует её в момент **массового входа по “учебнику”**.

Фаза поведения:

1. **Толпа формирует фигуру** — с чёткими волнами и диапазоном
2. Алгоритм **ждёт пробоя и входа толпы**
3. Затем — **разворачивает движение против**
4. Вызывает **ликвидации и откат**, разрушая доверие к структуре
5. После этого — **реальное движение** уже вне паттерна

📌 В отличие от Pattern Baiting — здесь **алго не строит паттерн**, а **атакует готовый**.

### II. Отличие от других ловушек

| **Признак** | **Classic Pattern Trap** | **Pattern Baiting** |
| --- | --- | --- |
| Кто строит паттерн | Толпа | Алгоритм |
| Время формирования | Долго (10+ свечей) | Быстро (5–8) |
| Структура | Чёткая, плавная | Рваная, шумная |
| Поведение до пробоя | Объём накапливается | Объём затухает |
| Поведение после пробоя | Резкий разворот | Моментальный сброс |
| Follow-up объём | Пропадает | Может быть |
| Поведение OI | Растёт → замирает | Часто нейтральный |

### III. Методы и метрики

| **Метрика** | **Что отслеживать** | **Где брать** |
| --- | --- | --- |
| Длина диапазона | ≥ 10 свечей | /market/kline |
| ATR диапазона | Должен быть < среднего | вычисляется вручную |
| Объём на пробое | > 1.5× среднего | volume[i] |
| Направление дельты | Совпадает с пробоем | /recent-trade |
| Поведение OI | Растёт до пробоя, замирает после | /open-interest |
| Цена после пробоя | Возвращается внутрь | close[i+1] < close[i] |
| Ликвидации | Присутствуют после пробоя | WebSocket /all-liquidation |

### IV. Формулы и логика

### 1. Паттерн “созрел”

```python
if len_range >= 10 and atr_now < atr_avg and volume_pre_breakout > avg_volume:    context = "classic pattern likely"
```

### 2. Подтверждённый пробой

```python
if volume[i] > avg_volume * 1.5 and delta[i] > avg_delta * 1.5:    breakout = True
```

### 3. Нет продолжения

```python
if close[i+1] < close[i] and volume[i+1] < volume[i] * 0.6:    follow_through = False
```

### 4. OI замирает

```python
delta_OI = OI[i] - OI[i-1]if delta_OI > 500 and price_change < 0.2:    trapped = True
```

### 5. Ликвидации

```python
if sum_liq > 1_000_000 and not follow_through:    signal = "classic trap"
```

### V. Поведение бота

Если:

- Есть **устойчивая фигура** ≥ 10 свечей
- **Объём и дельта растут на пробое**
- **Цена не уходит**, а возвращается
- OI замирает, ликвидации вспыхнули
- Следующая свеча показывает откат или слабый импульс

**Бот:**

- Помечает classic_pattern_trap = True
- **Запрещает вход** в сторону пробоя на 10–15 минут
- Ожидает:
    - **ретеста уровня** + подтверждение
    - или **нового накопления** с другими условиями
- **В фазе фальшпробоя** — допускается вход в обратку при подтверждённой слабости (падающий объём, снижение OI, свеча-захлоп)

### VI. Python-фрагмент логики

```python
import statistics

def detect_classic_trap(klines, oi_data, delta_list, liq_total):
    signals = []
    for i in range(10, len(klines)-2):
        highs = [float(k[2]) for k in klines[i-10:i]]
        lows = [float(k[3]) for k in klines[i-10:i]]
        range_size = max(highs) - min(lows)
        atr = statistics.mean([float(k[2]) - float(k[3]) for k in klines[i-10:i]])
        
        o, h, l, c, v = map(float, klines[i][1:6])
        next_c = float(klines[i+1][4])
        delta = delta_list[i]
        oi_now = float(oi_data[i]['openInterest'])
        oi_prev = float(oi_data[i-1]['openInterest'])
        delta_oi = oi_now - oi_prev
        price_change = abs(c - o) / o * 100

        avg_vol = statistics.mean([float(k[5]) for k in klines[i-10:i]])

        if range_size < atr * 1.2 and v > avg_vol * 1.5:
            if next_c < c and delta > 0 and delta_oi > 500 and price_change < 0.2 and liq_total[i] > 1_000_000:
                signals.append((int(klines[i][0]), "Classic Pattern Trap"))
    return signals

```

### VII. Сводка условий

| **Условие** | **Значение** |
| --- | --- |
| Длина диапазона до пробоя | ≥ 10 свечей |
| ATR диапазона | < среднего по рынку |
| Объём на пробое | > 1.5× среднего |
| Дельта | Направлена в сторону пробоя |
| OI перед пробоем | Растёт |
| OI после пробоя | Не поддерживает |
| Follow-up свеча | Возврат внутрь диапазона |
| Ликвидации | Есть, но импульс затухает |
