# Cтопы: тейки

### **✅ I. ОСНОВНОЙ ПРИНЦИП (ГЛАВНОЕ)**

📌 Бот **не торгует паттерны** — он **реагирует на слабость алгоритма** после манипуляции.

**Значит:**

- Вход — **только после окончания манипуляции**, на **структурном подтверждении** (не импульсе).
- Стоп — **за уровнем манипуляции**, но **вне зоны сбора ликвидности**.
- Тейк — **по скорости/объёму/ликвидности** → там, где начнётся откат.

### **🧭 II. СЛОЙ 1: КАК БОТ ОПРЕДЕЛЯЕТ УРОВНИ**

Уровни не рисуются руками. Бот **сам формирует ключевые уровни** на основе:

| **Метрика** | **Описание** |
| --- | --- |
| manipulation_high | HIGH свечи с манипуляцией |
| manipulation_low | LOW той же свечи |
| trap_entry_body | Тело свечи, в которой произошёл разворот |
| impulse_base | LOW или HIGH импульсной свечи перед входом |
| mid_range_value | (High + Low) / 2 за последние 10 свечей, если это флэт |
| delta_flip_zone | Зона, где дельта резко сменила направление, а цена — нет |

**Эти зоны формируют уровни для:**

- стопа
- входа (на ретесте)
- контрольной зоны для тейка

### **🧬 III. СЛОЙ 2: РАСЧЁТ ВХОДА**

**🔹 Общий принцип:**

Бот **не входит по пробою**, а **входит после манипуляции** на **возврате в зону**, либо при **структурном подтверждении**.

**📐 Формула расчёта входа:**

```python
entry_price = trap_zone_entry + atr_1m * X
```

- trap_zone_entry — цена тела свечи, где подтверждён разворот
- atr_1m — средний true range (волатильность)
- X — коэффициент (0.1–0.3), чтобы не входить прямо в ловушку

**📌 Условия входа:**

- активная манипуляция завершена (trap_X.triggered = True → False)
- свеча с подтверждением (объём ↑, дельта в сторону тела, follow-through)
- **нет** быстрых отмен стакана (признак spoofing-а)
- нет противоположной манипуляции в радиусе 5 свечей

### **🛡 IV. СЛОЙ 3: РАСЧЁТ СТОПА**

**🔹 Принцип:**

**Стоп ставится там, где алго уже "забрал" ликвидность.** То есть — туда он **не вернётся без новой манипуляции**.

**📐 Формула стопа:**

```python
if trap:
    stop = trap_low - atr_1m * 0.3
elif импульс:
    stop = импульс_base - atr_1m * 0.5
elif flat:
    stop = range_edge - atr_1m * 0.2
```

Идеально: **поставить стоп туда, куда алго уже ударил**, но входить **после реакции**, не сразу.

### **💰 V. СЛОЙ 4: РАСЧЁТ ТЕЙКА**

**🔹 Принцип:**

Выход не фиксированный (типа 1:2), а по **реакции рынка**:

- если объём умирает → закрывать.
- если цена доходит до "зоны предыдущей ликвидности" → частично закрывать.
- если появляется **новая манипуляция** против позиции → выходить полностью.

**📐 Формула тейка:**

```python
take_1 = entry + atr_1m * 1.2  # первая цель — по структуре
take_2 = уровень последней ликвидации + atr_1m * 0.5
take_3 = trailing — по снижению объёма
```

- **Trailing logic**:

```python
if volume[i] < volume[i-1] * 0.7 and dxy != confirm:
exit_position()
```

### **🔁 VI. БЫСТРЫЙ ВЫХОД, ЕСЛИ БОТ НЕ ПОПАЛ В ДВИЖЕНИЕ**

Бот отслеживает **3 признака ложного входа**:

| **Признак** | **Условие** |
| --- | --- |
| Нет follow-through | Следующая свеча слабая, объём < 50% |
| OI растёт против нас | ΔOI > 300 в обратную сторону |
| Дельта против тела | Покупают — свеча красная (или наоборот) |

📌 Если **2+ признака** активны → бот **закрывает позицию на следующий open**.

### **🧠 VII. КЛЮЧЕВАЯ ЛОГИКА (резюме)**

```python
if trap_ended and confirmation_candle and no_opposite_signal:
entry = price + atr_1m * 0.2
stop = manipulation_low - atr_1m * 0.3
take = entry + atr_1m * 1.5
monitor_followthrough()
else:
wait()
```

### **🎯 Итоговая стратегия вход/стоп/тейк**

| **Элемент** | **Принцип** |
| --- | --- |
| 🎯 Вход | После манипуляции, по подтверждению, **не по свечке**, не по пробою |
| ❌ Стоп | За хвостом ловушки, не в зоне сбора, с запасом по ATR |
| 💰 Тейк | По structure → объёму → ликвидности → trailing |
| ⏳ Быстрый выход | Нет follow-up, дельта и OI не поддерживают — выходим |
