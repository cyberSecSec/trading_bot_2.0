1. **Работа против открытого интереса**
- Видит, где растёт OI (лонги/шорты), и **заставляет толпу почувствовать уверенность**

# **🛠 Манипуляция №15: Работа против открытого интереса (Open Interest Trap)**

### I. Что это и как работает

**Суть манипуляции:**

Алгоритм следит за структурой открытого интереса (OI). Как только:

- OI **постоянно растёт** (прибавление позиций),
- цена **не даёт прогресса**, — значит толпа "заперта".

Далее:

1. Толпа уверена в продолжении
2. Алго запускает **импульс против ожидания**
3. Запускается **каскад ликвидаций**
4. Рынок "очищается", после чего начинается реальное движение

### II. Поведение на графике (по фазам)

| **Фаза** | **Признаки** |
| --- | --- |
| Рост OI без движения | Цена стоит, RSI растёт, свечи "вверх", но без объёма |
| Резкий разворот | Импульсная свеча, ликвидации, дельта паническая |
| Блокировка ретеста | Цена **не возвращается** к зоне пробоя |

### III. Метрики и источники

| **Метрика** | **Что отслеживаем** | **Источник** |
| --- | --- | --- |
| Изменение OI | OI растёт на 500–1000+ | /market/open-interest |
| Изменение цены | < 0.2% | /market/kline |
| Дельта | Односторонняя агрессия | /recent-trade |
| Ликвидации | > $1 млн | WebSocket /all-liquidation |
| Ретест | Цена **не возвращается** | /market/kline |

### V. Поведение бота

📍 **Фаза 1 — Наблюдение:**

- Следит за накоплением OI при слабом движении цены
- Если OI ↑, объёмы нормальные, но цена не растёт → **ставит метку ловушки**

📍 **Фаза 2 — Импульс и ликвидации:**

- Если идёт резкий откат, ликвидации, дельта в обратную сторону:
    - Бот **запрещает вход** в сторону тренда на 10–15 минут

📍 **Фаза 3 — Разрешение/перепроверка:**

- Если:
    - цена **не вернулась** к пробитому уровню
    - объём нормальный, OI начинает снижаться → вход **разрешён в новую сторону**
- Если:
    - цена вернулась обратно → бот ждёт новую структуру + follow-up объём

### VI. Детектор (Python-фрагмент)

```python
def detect_OI_trap(klines, oi_data, delta_list, liq_data):
    signals = []
    for i in range(5, len(klines) - 1):
        o, h, l, c, v = map(float, klines[i][1:6])
        price_change = abs(c - o) / o * 100

        oi_now = float(oi_data[i]['openInterest'])
        oi_prev = float(oi_data[i - 1]['openInterest'])
        delta_oi = oi_now - oi_prev

        delta = delta_list[i]
        avg_delta = statistics.mean(delta_list[i-5:i])
        liq = liq_data[i]

        if delta_oi > 800 and price_change < 0.2 and delta > 1.5 * avg_delta and liq > 1_000_000:
            signals.append((int(klines[i][0]), "Open Interest Trap"))

    return signals
```

### VII. Сводка условий

| **Условие** | **Значение** |

### VIII. Поведение бота по фазам

| **Фаза** | **Действие бота** |
| --- | --- |
| Рост OI без движения | Маркирует ловушку, наблюдает |
| Импульс + ликвидации | Блокирует вход по текущему направлению |
| Цена не вернулась | Разрешает вход по новой структуре с follow-through |
| Цена вернулась обратно | Ждёт повторный сигнал, подтверждённый объёмом + OI |
