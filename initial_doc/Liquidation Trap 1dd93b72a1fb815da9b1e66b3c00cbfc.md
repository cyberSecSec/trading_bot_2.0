# Liquidation Trap

1. **Вброс ликвидаций для поджига движения (Liquidation Trap)**
- Алго специально вызывает цепочку ликвидаций (на фьючах)
- Активирует каскад, чтобы **резко ускорить цену**
- А потом входит в противоположную сторону, когда волна закончена

## Манипуляция №9: Вброс ликвидаций для поджига движения (Liquidation Trap)

### 1. Что это и как работает

**Суть манипуляции:**

Алгоритм специально инициирует пробой уровня с целью спровоцировать **массовые ликвидации** на фьючерсах. Это создаёт каскадное движение, после которого:

1. Алго **впрыскивает объём** для ускорения цены
2. **Срабатывают стопы и ликвидации** — цена "летит"
3. **После истощения ликвидов** — рынок резко разворачивается

**Фазовость манипуляции:**

- **Фаза I** — спровоцированный пробой
- **Фаза II** — всплеск ликвидаций + ускорение
- **Фаза III** — разворот/фиксация после каскада

Алго целенаправленно **ждёт критический момент**, чтобы "зажечь" каскад — и потом вывернуть рынок против запоздавших.

### 2. Как это выглядит на графике и в стакане

- Свеча-пробой с крупным объёмом и длинным телом
- Вспышка ликвидаций в WebSocket /all-liquidation
- Следующая свеча — либо откат, либо захлоп
- Часто: **1 свеча в продолжение**, затем — **разворот**
- OI резко падает после пробоя: фиксируют, закрываются, ликвидируются
- Признак: дельта в сторону импульса, но рынок **теряет инерцию**

### 4. Формулы и логика бота

**1. Всплеск ликвидаций:**

```python
liq_sum = sum(liq['qty'] * liq['price'] for liq in last_10_sec_liquidations)
if liq_sum > 1_500_000:
    liq_flag = True
```

**2. Импульсная свеча:**

```python
price_range = high - low
price_change = abs(close - open) / open * 100
if price_change > 0.8 and volume > avg_volume * 2:
    impulse_flag = True
```

**3. OI падает после пробоя:**

```python
oi_change = oi_now - oi_prev
if oi_change < 0 and volume_now > avg_volume * 1.5:
    post_liq_exit = True
```

4. **Следующая свеча — поглощение:**

```python
if close[i+1] < open[i+1] and close[i+1] < low[i]:  # для long-trap
    reversal_flag = True
```

**5. Потеря follow-up:**

```python
vol_follow = volume[i+1] < volume[i] * 0.5
price_stalls = abs(close[i+1] - close[i]) < close[i] * 0.15 / 100
```

### 5. Поведение бота

Если одновременно:

- Ликвидации > 1.5 млн USDT за 10 сек
- Свеча > 0.8% тела и объём > 2× среднего
- Дельта +, OI ↓
- Следующая свеча против пробоя или боковая
- Нет follow-up объёма

**Тогда:**

- бот маркирует зону как liquidation_trap = True
- **запрещает вход по тренду**
- включает **режим паузы/наблюдения**
- если на обратке появляется:
    - свеча с телом > 60%,
    - объём растёт,
    - дельта меняется направленно,→ возможен **контртрендовый вход** (через структуру)
- **▪️ Модуль “Trap-архетипы” (встроенный)**
    
    Если активен liquidation_trap = True, бот дополнительно классифицирует ловушку:
    
    | **Тип ловушки** | **Условия** | **Реакция бота** |
    | --- | --- | --- |
    | **Liquidation Trap** | Ликвидации + импульс + OI ↓ + разворот свечи | Стоп, пауза, наблюдение |
    | **Volume Injection Trap** | Всплеск объёма + слабый close + wick_ratio > 0.6 | Игнорировать вход, ждать подтвержд. |
    | **Stair-Step Trap** | 3+ импульса + OI ↑ + нет закрепа | Фиксация паттерна, запрет входа |
    | **Pattern Bait Trap** | Пробой паттерна + вход толпы + откат | Блокировка по визуальной ловушке |

### 6. Python-блок (обновлённый)

```python
import statistics

def detect_liquidation_trap(candle, next_candle, liq_volume, oi_now, oi_prev, last_volumes):
    open_, high, low, close, volume = map(float, candle[1:6])
    next_open, next_close, next_low, next_volume = map(float, (next_candle[1], next_candle[4], next_candle[3], next_candle[5]))
    
    avg_volume = statistics.mean(last_volumes)
    price_change = abs(close - open_) / open_ * 100
    oi_change = oi_now - oi_prev
    followup_volume_drop = next_volume < volume * 0.5
    reversal = next_close < open_ and next_close < low
    stealth_exit = oi_change < 0 and followup_volume_drop

    if (
        liq_volume > 1_500_000 and
        volume > avg_volume * 2 and
        price_change > 0.8 and
        stealth_exit and
        reversal
    ):
        return {
            "trap": True,
            "trap_type": "Liquidation Trap",
            "liq_volume": liq_volume,
            "volume_ratio": round(volume / avg_volume, 2),
            "oi_drop": oi_change,
            "followup_volume_drop": followup_volume_drop,
            "reversal_detected": True
        }
    return {"trap": False}

```
