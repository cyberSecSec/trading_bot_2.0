

Разработать базовую интеграцию с Bybit для модуля Trading APIs & Exchange системы VANTA. Задача включает реализацию компонентов для работы с API Bybit согласно следующим требованиям:

1. Создать специализированные адаптеры:
   - BybitConnectionManager (exchange_api/exchanges/bybit/connection_manager.py) - расширение ConnectionManager с реализацией HMAC SHA256 аутентификации для Bybit API
   - BybitWebSocketManager (exchange_api/exchanges/bybit/websocket_manager.py) - расширение WebSocketManager с поддержкой специфичных форматов сообщений Bybit

2. Реализовать определение основных эндпоинтов Bybit API v5 (exchange_api/exchanges/bybit/endpoints.py):
   - Рыночные данные: OHLCV, стакан ордеров, сделки, открытый интерес, ликвидации
   - Торговые операции: создание/отмена ордеров, управление позициями
   - Управление аккаунтом: баланс, история операций

3. Реализовать базовый клиент Bybit (exchange_api/exchanges/bybit/bybit_client.py):
   - Методы для получения рыночных данных
   - Методы для торговых операций
   - Методы для управления аккаунтом
   - Аутентификация с HMAC-SHA256

4. Разработать обработчики WebSocket сообщений (exchange_api/exchanges/bybit/websocket_handlers.py):
   - Обработка рыночных данных
   - Обработка торговых событий
   - Обработка системных сообщений

5. Обновить файлы:
   - exchange_api/exchanges/bybit/__init__.py для экспорта новых классов
   - Добавить примеры использования в README.md

Для реализации можно использовать уже созданные базовые классы: ConnectionManager, WebSocketManager и ReconnectionHandler.

Требования по аутентификации Bybit:
- Использовать HMAC-SHA256 для подписи запросов
- Учесть временные метки и проверку на replay-атаки
- Реализовать корректное формирование строки для подписи согласно документации Bybit API

Особое внимание уделить обработке ошибок, управлению повторными попытками и логированию.
