Твоя задача - реализовать базовую конфигурацию и утилиты для модуля Trading APIs & Exchange (задача 2 из бэклога разработки).

На основе документацииTrading APIs&Exchange backlog.md, создай следующие компоненты:

1. **Класс конфигурации клиента (exchange_api/core/config.py)**:
   - Создай/доработай класс ClientConfig со следующими характеристиками:
     - Параметры подключения к API (URL, ключи API)
     - Настройки соединения (таймауты, максимальное количество повторных попыток при ошибках)
     - Флаги режима работы (тестовый/боевой)
     - Валидация всех параметров при создании экземпляра
   - Реализуй методы для:
     - Загрузки конфигурации из файла JSON
     - Загрузки конфигурации из переменных окружения (используя python-dotenv)
     - Создания дефолтной конфигурации с безопасными значениями
   - Обеспечь безопасное хранение чувствительных данных (API ключи)
   - Используй Pydantic для валидации полей и типизации

2. **Система логирования (exchange_api/utils/logger.py)**:
   - Создай систему логирования с:
     - Различными уровнями детализации (DEBUG, INFO, WARNING, ERROR, CRITICAL)
     - Настраиваемым форматом сообщений с включением времени, уровня, модуля, функции
     - Настройкой вывода (консоль, файл)
     - Механизмом ротации логов при достижении определённого размера
   - Используй библиотеку loguru
   - Добавь возможность настраивать логирование из конфигурации клиента

3. **Иерархия исключений (exchange_api/exceptions.py)**:
   - Доработай базовый класс VantaTradingError со следующими атрибутами:
     - message: Сообщение об ошибке
     - code: Код ошибки (если применимо)
     - request_info: Информация о запросе, который привел к ошибке
     - response_info: Информация об ответе, который привел к ошибке
   - Создай/доработай специализированные исключения:
     - ConnectionError - ошибки соединения с биржей
     - AuthenticationError - ошибки аутентификации
     - RateLimitError - превышение лимитов запросов
     - ValidationError - ошибки валидации данных
     - OrderError - ошибки операций с ордерами
     - PositionError - ошибки управления позициями
     - MarketDataError - ошибки получения рыночных данных
     - WebSocketError - ошибки WebSocket соединений
     - ConfigurationError - ошибки конфигурации
     - ExchangeError - специфичные ошибки биржи
     - UnexpectedError - неожиданные ошибки
