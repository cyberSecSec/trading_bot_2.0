# Задача: Разработка сервиса для доступа к OHLCV данным в модуле Trading APIs & Exchange

## Контекст
Я работаю над модулем Trading APIs & Exchange системы VANTA, который обеспечивает унифицированный доступ к API криптовалютных бирж. На предыдущем этапе
были разработаны базовые интерфейсы (`IMarketDataProvider`, `IMarketDataRestProvider`, `IMarketDataStreamProvider`), модели данных и компоненты соединения.

Сейчас я перехожу к "Этапу 2: Реализация сервисов для рыночных данных", начиная с "Задачи 1: Разработка сервиса для доступа к OHLCV данным".

## Описание задачи
Необходимо реализовать сервис для доступа к историческим OHLCV (Open, High, Low, Close, Volume) данным через REST API и получения обновлений в режиме реального времени через WebSocket API. Сервис должен работать с API Bybit, но быть спроектирован с возможностью расширения для других бирж.

## Требования к реализации

1. Создать реализацию интерфейса `IMarketDataRestProvider` для OHLCV данных, включая:
   - Метод `get_klines` для получения исторических данных с поддержкой всех параметров API Bybit
   - Обработку ошибок и ограничений API
   - Нормализацию данных в соответствии с моделью `KlineData`

2. Создать реализацию интерфейса `IMarketDataStreamProvider` для получения OHLCV данных в реальном времени, включая:
   - Метод `subscribe_to_klines` для подписки на обновления OHLCV данных
   - Метод `unsubscribe_from_klines` для отписки от обновлений
   - Корректную обработку подписок и отписок
   - Нормализацию полученных данных в формат `KlineData`

3. Создать единый сервис, объединяющий оба интерфейса для удобства использования.

## Структура файлов для реализации
- `services/bybit/market_data_rest_service.py` - REST-провайдер для рыночных данных
- `services/bybit/market_data_stream_service.py` - WebSocket-провайдер для рыночных данных
- `services/bybit/market_data_service.py` - Объединенный сервис

## Детали реализации REST-провайдера

REST-провайдер должен использовать `ConnectionManager` для выполнения HTTP-запросов к API Bybit. Метод `get_klines` должен:
1. Принимать параметры: символ, интервал, лимит, время начала, время окончания
2. Валидировать параметры
3. Преобразовывать параметры в формат запроса API Bybit
4. Выполнять запрос к эндпоинту `/v5/market/kline`
5. Обрабатывать ответ и преобразовывать данные в список объектов `KlineData`
6. Обрабатывать ошибки и исключения

## Детали реализации WebSocket-провайдера

WebSocket-провайдер должен использовать `WebSocketManager` для установки соединения и управления подписками. Метод `subscribe_to_klines` должен:
1. Принимать параметры: символ, интервал, функцию обратного вызова
2. Формировать имя канала подписки в формате `kline.{interval}.{symbol}`
3. Подписываться на канал через `WebSocketManager`
4. Регистрировать обработчик сообщений, который будет:
   - Фильтровать сообщения, относящиеся к данной подписке
   - Преобразовывать данные из формата Bybit в объекты `KlineData`
   - Вызывать переданную функцию обратного вызова с преобразованными данными
5. Возвращать идентификатор подписки для последующей отписки

## Детали объединенного сервиса

Объединенный сервис должен:
1. Инкапсулировать REST и WebSocket провайдеры
2. Реализовывать интерфейс `IMarketDataProvider`
3. Делегировать вызовы соответствующим провайдерам
4. Обеспечивать управление ресурсами (подключение, отключение)

## Примечания по безопасности и производительности
1. Обеспечить безопасное освобождение ресурсов при завершении работы
2. Реализовать механизмы обработки ограничений API (rate limiting)
3. Оптимизировать преобразование данных для высокой производительности
4. Не хранить исторические данные в сервисе, а лишь предоставлять доступ к ним

## Примеры использования

Привести примеры того, как другие модули будут использовать созданный сервис:

```python
# Пример использования REST API
async def example_rest():
    provider = BybitMarketDataRestProvider(config)
    klines = await provider.get_klines(
        symbol="BTCUSDT",
        interval=KlineInterval.MIN_1,
        limit=100
    )
    for kline in klines:
        print(f"Время: {kline.timestamp}, Закрытие: {kline.close}")

# Пример использования WebSocket API
async def example_ws():
    provider = BybitMarketDataStreamProvider(config)

    async def on_kline(kline):
        print(f"Получено обновление свечи: {kline.symbol} {kline.interval}")
        print(f"O: {kline.open}, H: {kline.high}, L: {kline.low}, C: {kline.close}")

    subscription_id = await provider.subscribe_to_klines(
        symbol="BTCUSDT",
        interval=KlineInterval.MIN_1,
        callback=on_kline
    )

    # ... позже
    await provider.unsubscribe_from_klines(subscription_id)
```
